# Graded Reader — читалка для изучения английского

Книги Free Graded Readers (Paul Nation). Нажал на слово — получил перевод в контексте (Claude), транскрипцию и озвучку. Слова сохраняются в словарь (Supabase), есть повторение карточками, как в Anki. Слова из словаря подсвечиваются в тексте.

```
frontend/index.html   → GitHub Pages (один файл)
backend/              → Railway (Flask)
Supabase              → проект «english-trainer бот», таблицы reader_* уже созданы
```

## Вход и пользователи

Каждый входит по своей почте: вводит адрес, получает 6-значный код и вводит его. Пароля нет, ключей никто не вводит. У каждого свой словарь и прогресс, на любом устройстве. Страница не содержит ни одного ключа: вход идёт через сервер.

Лимит: `DAILY_LIMIT` новых переводов на человека в день (по умолчанию 300). Уже переведённое берётся из общего кэша бесплатно и без лимита.

## Где что живёт

| Часть | Где |
|---|---|
| Страница | GitHub Pages: https://pavelakc.github.io/english-reader/ (файл `index.html` в корне) |
| Сервер | Railway, проект `english-reader`, сервис `reader-api` (папка `backend`), деплой при каждом push в `main` |
| База | Supabase «english-trainer бот»: `reader_book_pages`, `reader_translations` (общие), `reader_user_vocab`, `reader_user_progress`, `reader_usage` (по пользователям) |

Переменные Railway: `ANTHROPIC_API_KEY`, `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, необязательные `CLAUDE_MODEL`, `DAILY_LIMIT`, `ALLOWED_ORIGINS`, `SITE_URL`.

## Настройка Supabase для входа (один раз)

1. **Authentication → URL Configuration**: Site URL = `https://pavelakc.github.io/english-reader/`.
2. **Authentication → Emails → Templates**: в шаблоны **Magic Link** и **Confirm signup** добавь строку с кодом: `<p>Код для входа: <b>{{ .Token }}</b></p>`.
3. **Чтобы письма приходили всем, а не только тебе:** Authentication → Emails → **SMTP Settings** → подключи свою почту (например Gmail с паролем приложения: host `smtp.gmail.com`, port `465`, user — твой gmail, password — пароль приложения).

## Как пользоваться

- **Книги**: выбери книгу и уровень. Первое открытие занимает 10–60 секунд: сервер скачивает PDF с сайта университета и режет его на страницы. Дальше всё грузится мгновенно из Supabase.
- **Нажатие на слово**: перевод именно в этом предложении, форма слова (went → go), транскрипция, фразовые глаголы, короткая заметка по грамматике. 🔊 озвучка, 🐢 медленно.
- **«Перевести фразу» / «🔊 Фраза»**: перевод и озвучка всего предложения.
- **▶︎ вверху**: чтение страницы вслух с подсветкой текущего предложения.
- **Свайп влево/вправо**: следующая/предыдущая страница.
- **Подсветка**: слова, которые ты учишь, выделены жёлтым. Выученные можно подсветить зелёным в настройках.
- **Повтор**: карточки «Снова / Трудно / Хорошо / Легко». Когда интервал доходит до 30 дней, слово автоматически становится «выученным».

## Уровни

| Уровень | Словарь | Примерно |
|---|---|---|
| 1200 | 1 200 слов | A2 |
| 4000 | 4 000 слов | B1+ |
| 6000 | 6 000 слов | B2 |
| 8000 | 8 000 слов | C1 |

Начни с **Fire on the Mountain** или **The Burning Bed**, потом переходи на 4000: **Sherlock Holmes**, **The Time Machine**.

Две книги на 1200 слов старые, и если PDF окажется сканом без текста, приложение честно скажет, что открыть её нельзя.

## Локальный запуск (для отладки)

```bash
cd backend
pip install -r requirements.txt
ANTHROPIC_API_KEY=... python app.py   # без SUPABASE_* данные хранятся в памяти
```
